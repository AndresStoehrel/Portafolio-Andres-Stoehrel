# Skill: cerrar sesión

Si hubo cambio de producto, decisión o blocker:

1. `state/NOW.md`: hecho / pendiente / blockers / foco. Fechar.
2. Decisión nueva → `decisions/YYYY-MM-DD-slug.md` + fila en `contexto/decisiones.md`.
3. Trampa nueva → 5–10 líneas en `gotchas/ui.md`.
4. Sesión larga → `logs/YYYY-MM-DD-slug.md` (qué, por qué, archivos, no transcribir).
5. Procedimiento repetido 2+ veces → `skills/` + fila en routing de `AGENTS.md`.
6. `AGENTS.md` solo si cambió un invariante o el mapa.

No reescribir historial. Append o reemplazar el estado actual.
